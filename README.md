# Portefólio de Tiago Laim Rodrigues

Site estático de apresentação profissional, projetos, experiência, formação e tecnologias. O HTML é servido diretamente, sem framework ou dependências de runtime. O CSS está organizado em módulos e inclui o layout Bento responsivo, diagramas vetoriais e suporte a movimento reduzido.

O CV para download está disponível em `CV_Tiago_Rodrigues.pdf`.

Para pré-visualizar localmente, execute `python3 -m http.server 8000` na raiz do projeto e abra `http://localhost:8000`.
